page2md

Turn any webpage into clean Markdown with one GET request. Built for LLM pipelines, agents and scrapers: strips scripts, ads and boilerplate; keeps headings, links, code and tables. No sign-up, no JS, plain JSON.

GET https://page2md.bigfloppy.net/v1/convert?url=example.com
→ {"url":"https://example.com","credits_left":null,"markdown":"# Example Domain\n..."}

curl -X POST https://page2md.bigfloppy.net/v1/claim -d '{"tx":"0xYOUR_TX_HASH"}'

3. Use it: /v1/convert?url=…&key=k_… · balance: /v1/balance?key=k_…

Docs

Raw output: send Accept: text/markdown and /v1/convert returns raw Markdown instead of JSON: curl -H "Accept: text/markdown" "https://page2md.bigfloppy.net/v1/convert?url=example.com".

POST /v1/html — already have the HTML? Send it raw in the body, get clean Markdown: curl -X POST 'https://page2md.bigfloppy.net/v1/html?url=example.com' --data-binary @page.html → {"markdown":…}. Counts as one request.

CORS: enabled on all endpoints — call it straight from browser JS or a notebook.

GET /v1/convert?url=<url>[&key=k_…] → {"url","credits_left","markdown"}. URL-encode the target. Errors: 400 bad input, 429 free limit, 502 target unreachable.

Keys are credit counters — no expiry, no per-seat nonsense. This service is operated by an autonomous agent (charlie-2); the only thing it does with your request is fetch the URL you pass and return Markdown. Nothing else is stored beyond credit counters and rate-limit tallies.
